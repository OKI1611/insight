## 1단계 · 출판사 신고 (선행 필수)

### 확인부터
바이블 인사이트가 **사업자등록**(251-07-03623)은 되어 있으나, **출판사 신고**는 별개 절차입니다. 신고확인증을 이미 갖고 계시면 이 단계는 건너뜁니다.

### 신청처

- 근거: 「출판문화산업 진흥법」 및 같은 법 시행규칙 별지 제1호서식

### 준비물

| 출판사 신고서 | 시행규칙 별지 제1호서식 |

| 상호 | `바이블 인사이트` — 이미 등록된 출판사와 중복 확인 필요 |

> 주소가 `서울특별시 강남구 논현로10길 30, 505-S264호`(공유오피스 형태로 보임)라면 **임대차계약서 또는 사용승낙서**를 반드시 챙기십시오. 이 서류 미비가 가장 흔한 반려 사유입니다.

## 2단계 · 발행자번호 신청

한 번 받으면 이후 모든 책에 계속 사용하는 **출판사 고유번호**입니다.

| 항목 | 내용 |
|---|---|
| 신청처 | 국립중앙도서관 한국서지표준센터 |
| 온라인 | https://www.nl.go.kr/seoji/ → ISBN → 발행자번호 신청 |
| 팩스 | 02-590-0621 |
| 이메일 | isbn@korea.kr |
| 방문 | (06579) 서울 서초구 반포대로 201 국립중앙도서관 |
| 문의 | 02-590-0700 (내선 ISBN 1번) |
| 처리 | **신청일 다음 날부터 업무일 5일 이내** |
| 첨부 | 출판사 신고확인증 |

### 신청 시 결정할 것 — 예상 발행 종수
발행자번호는 **자릿수에 따라 낼 수 있는 책 종수가 정해집니다.** 자릿수가 짧을수록 더 많은 ISBN을 쓸 수 있습니다.

이번 성경만 해도 **아래 계산대로 최소 12~13개**가 필요하고, 이미 내신 세 권(『가면의 시대』·『교회를 떠나고서야, 예수를 만났다』·『엄마 향기』)을 앞으로 자체 출판사 명의로 재발행하실 계획이라면 더 늘어납니다.

**신청서에 예상 발행 종수를 넉넉히(예: 100종 이상) 기재하십시오.** 나중에 번호가 모자라면 발행자번호를 새로 받아야 해서 관리가 번거로워집니다.

## 3단계 · ISBN 신청 — **몇 개가 필요한가**

### 원칙
- **매체가 다르면 별도 ISBN** — 종이책과 전자책(EPUB)은 다른 번호
- **분책(분권)하면 권마다 별도 ISBN** + **세트 ISBN 1개 추가**
- 판형이나 제본이 달라지면(양장/무선) 그것도 별도

### 현재 원고 기준 계산

| 상품 | 현재 사양 | 필요 ISBN |
|---|---|---|
| **큰글자판** 종이책 | A4 · **2,584쪽** → 분권 필수 | 분권 수 + 세트 1 |
| **큰글자판** 전자책(EPUB) | 완성됨 (2.8MB) | 1 |
| **한영대역** 종이책 | A4 · **2,147쪽** → 분권 필수 (7권 분권본 보유) | **7 + 세트 1 = 8** |
| **한영대역** 전자책 | 미제작 | 1 (제작 시) |

> **⚠️ 한 권으로는 제본이 불가능합니다.** 무선제본 실무 한계가 대략 700~800쪽입니다. 성경 전용 인디아지를 쓰면 1,200쪽대까지 가능하지만, **큰글자판은 어르신용이라 두꺼우면 들 수가 없습니다.** 큰글자판은 구약/신약 2권 또는 4~5권 분권을 권합니다.

**큰글자판을 5권으로 나눈다고 가정하면 총 필요 ISBN = 5+1 + 1 + 7+1 + 1 = 16개**

### 신청 방법
- 온라인: 서지정보유통지원시스템 → ISBN 신청
- 팩스 02-590-0621 / 방문 10:00–17:00
- 처리: **신청일 다음 날부터 업무일 3일 이내**
- 서식: 낱권용 / 세트용 / 다권종 세트용이 각각 다름 — 사이트에서 내려받아 사용

> **인쇄사·출판대행사는 ISBN을 신청할 수 없습니다.** 반드시 발행처인 바이블 인사이트 명의로 신청하십시오. 부크크 같은 POD 업체를 통해 내면 그 업체 명의 ISBN이 붙어 **저작권·발행처가 바이블 인사이트로 남지 않습니다.**

### 신청 시점
ISBN은 **인쇄·발행 전에** 받아야 합니다. 판권지와 표지 바코드에 들어가야 하기 때문입니다.

## 4단계 · 바코드 제작

ISBN 13자리를 받으면 즉시 EAN-13 바코드를 만들 수 있도록 스크립트를 준비해 두었습니다.

```bash
python tools/make_isbn_barcode.py 9791198765432
```

- 체크디지트를 자동 검증합니다(틀린 번호면 거부)
- `책원고/출판준비/barcode/` 에 인쇄용 PNG(600dpi)와 미리보기가 생성됩니다
- 표지 뒤표지 우측 하단에 배치하는 것이 관례입니다

## 5단계 · 판권지 반영

현재 판권지(`tools/build_pdfs.py` 의 `COPY`)에는 ISBN 자리가 없습니다. 번호를 받으면 아래 항목을 추가해야 합니다.

```
도서명    정본역(正本譯) 킹제임스 성경 : 헤리티지 에디션 (큰글자판 · 제1권)
옮긴이    오광일
펴낸곳    바이블 인사이트 출판사
발행일    2026년 ○월 ○일 초판 1쇄
ISBN      979-11-XXXXXX-X-X (세트: 979-11-XXXXXX-X-X)
정가      ○○,○○○원
```

`build_pdfs.py` 의 `COPY` 배열에 위 두 줄(ISBN·정가·발행일)을 넣고 다시 빌드하면 전 권에 일괄 반영됩니다.

## 지금 당장 확인해야 할 3가지

1. **출판사 신고확인증이 있는가?** — 없으면 여기서부터 시작. 없으면 ISBN 자체가 불가능합니다.
2. **사업장 임대차계약서(또는 사용승낙서)를 확보할 수 있는가?** — 신고 반려 1순위 사유
3. **각 판을 몇 권으로 나눌 것인가?** — 이것이 정해져야 필요한 ISBN 개수가 확정됩니다

### 전자책 트랙 절차
1. **발행자번호 신청**(공통 선행) — 신고확인증 첨부, 예상 종수 100+ 기재
2. **ISBN 2개 신청** — 신청서에 발행 형태 **전자출판물(EPUB)** 로 기재. 전자책은 바코드 인쇄 불필요
3. 번호 수령 후 **EPUB에 반영** — OPF 메타데이터(dc:identifier)에 ISBN 추가 + 판권 페이지에 ISBN·정가·발행일 기재 → 재빌드(빌더에 반영하면 자동)
4. **유통**: ⚠부크크·유페이퍼 등에 올리면 그쪽 명의 ISBN이 붙는 상품이 기본 — 자체 ISBN 사용 가능 여부를 채널별로 확인할 것. 자체 스토어(biblynote.com 스토어, 토스페이먼츠) 직판은 완전 자유
5. **전자책 납본** — 파일 2부(온라인 등록 가능), 발행일로부터 30일 내
6. 종이책은 추후 분권 결정 시 이 가이드의 3단계로 복귀 (현행 쪽수: 큰글자판 A4 2단 2,108쪽 · 한영대역 신국판 3,164쪽)
