# 다국어 용어 대조표 (신학·성경 용어)

바이블 인사이트 다국어판의 **기준 문서**입니다. 메뉴·안내문·강의·코너 글을 옮길 때 이 표를 먼저 따릅니다.
기계 번역 금지 — 문장마다 뜻을 옮기고, 아래 용어는 표의 표현만 씁니다. 표에 없는 용어가 나오면 표에 먼저 추가한 뒤 옮깁니다.

## 0. 원칙

1. **성경 인용은 각 언어의 공인된 옛 역본을 그대로** 쓴다(직접 번역 금지). 모두 저작권이 끝난 역본이다(아래 표).

## 4. 피해야 할 오역 (자주 틀리는 것)

- 휴거 ≠ "ascension"(승천은 그리스도의 승천에만). 휴거 = **Rapture**.
- 재림 ≠ "Advent"만 단독 사용 금지(대강절과 혼동). **Second Coming**.
- 일본어 携挙를 "引き上げ"로 풀어 쓰지 않는다(용어는 携挙, 성경 인용만 文語訳 '取り去られ').
- 중국어 被提를 "提升", "狂喜" 등으로 쓰지 않는다(rapture의 사전 뜻 '황홀' 오역 주의). 스페인어도 éxtasis 금지 → **arrebatamiento**.
- 중국어 大災難(신학 용어) / 大患難(和合本 인용) 구분.
- '정통 신앙고백 안의 해석 차이'를 "denominational dispute"(교단 분쟁)로 옮기지 않는다 → "differences of interpretation within historic orthodox faith".
