# 마태복음 정본역 킹제임스 성경 영한대역 성경책 — 기획/작업 상태

> 다른 컴퓨터에서 이어서 작업하기 위한 인수인계 문서. (마지막 저장: 세션 중단 시점)

## 목적
마태복음(→ 장차 전권) **정본역 킹제임스 성경 영한대역 성경책**. 흠정역(KJV) 영문 + 자체 새 우리말 번역 대역.
용도: **인쇄 출간(종이책) + 웹/전자책** 둘 다.

## 데이터 (이미 존재 · repo에 있음)
- `bible/en/Matthew-{장}.json` — 절별 객체 배열. 각 절:
  - `en` : KJV 영문 (공개 저작권)
  - `ko` : 자체 새 우리말 번역 (흠정역 전통 표기, 침례 하우스스타일)
  - `note` : 주해 (원어·배경·신학, 평균 ~190자)
  - `voc` : 어휘 `[[영단어, 품사, 뜻], ...]`
  - `idi` : 숙어 `[[구, 뜻], ...]`
  - `gra` : KJV 고어 어법 `[[구, 설명], ...]` (thou/shalt/begat 등)
- `bible/kr/` : 한글 번역만 있는 파일도 있음. 66권 대부분(`bible/en`·`bible/kr` 각 1189파일) 존재.

## 디자인 방향 (합의)
- **미감**: 흠정역 스터디 바이블 톤 — 미색 지면 · 남색 명조(Noto Serif KR) 국문 · Georgia 영문 · **앤티크 금박** 강조(장/절 번호·괘선). 라이트/다크 대응.
- **판형(레이아웃)**: ① 상하 대역(국문 위·영문 아래) ② 좌우 2단(국문|영문). **웹은 토글, 인쇄는 택1.**
- **부속 수준 옵션**: ①풀스터디(주해+어휘+어법) / ②주해중심(주해+어휘) / ③대역위주(대역만).

## ★ 현재 확정 방향 (사용자 최신 결정)
> "풀셋트가 너무 복잡" → 단순화.
- **2단 영한 대역 + 하단(장 끝) 절별 '영단어(어휘)만' 정리.**
- 주해·KJV 어법은 **제외**. 본문은 깔끔한 대역만, 어휘는 장 끝에 절별로 모아 학습.
- 산출물: `gen_diglot_2col.py` → `sample-diglot-2col.html`

## 산출물 (이 폴더)

## 인쇄 사양 (초안)
- 트림: **신국판 152×225mm** (조정 가능: 국판 148×210 / A5 / 사륙배판)
- 여백: 상16·좌우15·하16mm
- folio(페이지 번호)·러닝헤드는 최종 조판에서 확정(현재 샘플은 장식 풋터).
- 분량 참고(풀스터디 기준): 1–2장 48절 = 신국판 ~20p → 마태 전체 ~450p+. **대역위주/2단+단어만이면 훨씬 얇음.**

## 주의
- 생성기의 경로(`os.chdir`, OUT)가 **이 PC 절대경로/scratchpad 기준**. 다른 PC에선 경로만 맞춰 실행하면 됨. (repo 루트에서 `bible/en/*.json` 읽음)
- **HTML 샘플은 self-contained**라 어느 PC에서도 더블클릭으로 열림 — 규정/느낌 확인은 이걸로.
- 이 폴더는 `.assetsignore`로 Cloudflare **배포 제외**(사이트에 공개 안 됨), git에는 커밋되어 다른 PC로 동기화됨.
