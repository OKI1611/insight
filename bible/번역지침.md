# 「바이블 인사이트 역」 번역 지침서 (가칭)

BIBLY 바이블 인사이트 · 대표역자 오광일
*전권 일관성을 위한 기준 문서 — 모든 장(章) 번역은 이 지침을 따른다.*

---

## 1. 번역 철학
- **원어 우선**: 각 절을 **히브리어(구약)·헬라어(신약) 원문 의미**에서 새로 옮긴다. 영어 KJV는 구조·전통 참고용.
- **정확성과 권위의 균형**: 원문에 충실하되, **성경다운 권위와 무게가 느껴지는 문어체**로 옮긴다(§3). 짧게 끊지 말고 끊김 없이 낭독되는 가락을 살리며, 시가서는 히브리 평행법(parallelism)의 대구를 살린다.
- **독립 번역(저작권 안전)**: 개역·개역개정·흠정역 등 **기존 번역본의 문장 표현은 옮기지 않는다.** 공유 자산인 *용어·고유명사*만 통일에 참고한다.
  - ⚠️ **권위체 주의**: 권위체 어미(…하시니라/…이르노니/…느니라)는 누구나 쓰는 **문법 형태**라 자유다. 그러나 유명 구절의 **문장 자체를 그대로 옮기면 저작권 침해**다. **어미·문체는 권위체로 하되, 단어 선택·어순·표현은 반드시 자체적으로 달리 짓는다.** (예: '천지'→'하늘과 땅', '궁창'→'창공', '음침한 골짜기'→'그늘 골짜기', '부족함이 없으리로다'→'모자람이 없도다')

## 2. 표기·맞춤법
- **국립국어원 한글 맞춤법·외래어 표기법**을 따른다. (띄어쓰기·문장부호 포함. 예: '한곳', '물가')
- **성경 고유명사**는 한국 교회 전통 표기를 유지한다(예수, 모세, 다윗, 예루살렘, 바벨론 등) — 익숙함·접근성 우선.
- 인용·대화는 큰따옴표("…"), 인용 속 인용은 작은따옴표('…').

## 3. 문체·어조 (★전권 통일 — 성경의 권위)
성경은 사람의 글이 아니라 **하나님의 말씀**이다. 가볍고 일상적인 말투가 아니라, **권위와 무게가 느껴지는 한국어 성경 문어체**로 옮긴다. 옛 말투를 위한 옛 말투가 아니라, **읽는 이를 말씀 앞에 서게 하는 격조**다.

**서술·선언 종결 어미**
- 서술: …하니라 / …하더라 / …이니라 / …느니라 (예: "빛이 있었더라", "볼 수 없느니라")
- 명사+이다: …이라 / …이니라 (예: "유대인의 지도자라")
- 하나님·예수의 행위(존대): …하시니라 / …하셨더라 / …하시는도다 (예: "창조하시니라", "사랑하사")

**발화(말하는 장면)**
- 도입: 이르되 / 이르시되 / 말씀하시되 / 대답하여 이르시되 (사람이 하나님·예수께 아뢸 때는 **여짜오되**도 가능)
- 예수·하나님의 1인칭 선언: **…이르노니 / …하노라 / …느니라 / …하라** (예: "진실로 진실로 네게 **이르노니**", "이상히 여기지 **말라**")
- 사람이 하나님·예수께 아룀(겸양): …하나이다 / …이니이까 / …하소서 (예: "…아나이다", "어찌 …있사오리이까")

**연결 — 끊김 없이** (짧게 토막 내지 말고 성경 가락으로 잇는다)
- …하니 / …하매 / …하사 / …하시고 / …거늘 / …으되 / …이요(대구) / …하나니
- (예) "예수께서 대답하여 이르시되 …없느니라." / "…좋았더라. 저녁이 지나고 아침이 오니, 이는 첫째 날이니라."

**시가서**: 찬양·고백은 …로다 / …리로다 / …나이다 / …할지어다 로 가락을 살린다.

**금지**: …합니다 / …했다 / …이다 / …한다(평서 현대체)는 **본문에 쓰지 않는다**(해설·각주에서만 사용). 단, 권위체가 어색해 뜻이 흐려지는 곳은 정확성을 우선한다.

## 6. 운율 원칙
- **시가서(시편·잠언·아가·예레미야애가)**: 히브리 평행법의 대구를 한국어 가락으로 살린다. 짧고 균형 잡힌 행.
- **예언서**: 선포의 무게와 리듬. 산문은 정확하되 낭독 호흡을 살린다.
- **서신서**: 논리의 흐름을 끊지 않되 문장을 너무 길게 늘이지 않는다.
